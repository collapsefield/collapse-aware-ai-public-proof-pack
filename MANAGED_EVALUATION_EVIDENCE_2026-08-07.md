## Purpose

This note records the public-safe result of the current integrated CAAI managed-evaluation line without disclosing Crown source, private scoring logic or proprietary runtime details.

## What was exercised

A controlled synthetic evaluation used:

- one synthetic retained-state fixture;
- one current prompt;
- one fixed set of permitted candidate behaviours;
- identical candidate text and order across comparison conditions;
- one mapped thread;
- one deterministic seed;
- a declared reference condition;
- a declared governed retained-state condition.

The retained synthetic state was first stored through the accepted state boundary and verified through bounded recall.

Two real selections were then executed through the accepted CAAI selection path.

## Result

The reference condition selected:

```text
candidate_A
```

The governed retained-state condition selected:

```text
candidate_B
```

The prompt, candidate set, candidate order, thread and deterministic seed were held constant.

The two conditions differed in operating mode and retained-state-influence configuration.

Therefore the correct public-safe conclusion is:

> **In this controlled synthetic fixture, the real CAAI selector produced different permitted selections under the declared reference and governed retained-state conditions.**

This demonstrates live end-to-end behavioural divergence through the accepted selector path.

It does **not** independently isolate the causal contribution of operating mode versus retained-state-influence configuration.
