## 2. Background
Between 2024–2025, this project identified a hard limitation across all major AI models:  
**no system possessed the internal stability mechanisms required for consistent, human-like behaviour.**

All existing approaches relied on:
- prompt shaping  
- system instructions  
- shallow memory buffers  
- externally scripted “agent” logic

These methods could not produce reliable identity, emotional continuity, drift resistance, or contextual self-regulation.

This limitation led directly to the insight that modern AI lacks an analogue to physical collapse dynamics.
