## Current position

Collapse Aware AI (CAAI) is proprietary middleware for **retained-state behavioural selection**.

The core engineering question is:

> Can retained prior state change which permitted behaviour wins, while the reference path and resulting evidence remain inspectable?

The private engineering line has now progressed beyond the original Phase-1 Core Gold foundation into a controlled **local managed-evaluation package**.

## Live integration evidence

A controlled synthetic live evaluation used the same:

- current prompt;
- permitted candidate set;
- candidate text and order;
- mapped thread;
- deterministic seed.

The reference condition selected one permitted candidate and the governed retained-state condition selected a different permitted candidate.

This demonstrates **live end-to-end behavioural divergence through the real CAAI selector path**.

The comparison changed both the declared operating mode and retained-state-influence configuration, so it does **not** isolate the independent causal contribution of either setting. CAAI does not make a stronger causal claim from that fixture.

Both live selections produced durable private Decision Records. Those records were then projected through the accepted customer-safe evidence layer and linked back into the Phase-2 evidence chain.
