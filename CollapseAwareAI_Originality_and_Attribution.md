## Original Architecture Position

Collapse Aware AI is an original middleware architecture developed by **Marcos Verrell Moss Ross (M.R.)** under **Inappropriate Media Limited (t/a Collapse Aware AI)**.

CAAI does **not** require training a new foundation model and does **not** depend on modifying base model weights.

It is designed as a behavioural control layer around existing models, scripted decision engines, agent systems, games, or simulations.

The original contribution is the middleware architecture for governed, memory-weighted behavioural selection, including:

- structured continuity memory
- recency, salience, and anchor-based behavioural weighting
- Governor-mediated drift prevention
- contract-first integration boundaries
- collapse selection over candidate behaviours
- public/private separation between documentation and sealed Crown implementation

## Relationship to Existing AI Systems

Collapse Aware AI may operate with existing LLMs, game AI systems, scripted logic, or agent frameworks.

This does not make CAAI a derivative of those systems.

The distinction is:

> The underlying model or host runtime may generate candidate behaviour.  
> Collapse Aware AI governs, weights, constrains, and selects behaviour through its middleware logic.

The public claim is therefore not that CAAI invented base models, transformers, game AI, or agent frameworks.

The public claim is that CAAI defines an original middleware control architecture for memory-weighted, governor-constrained behavioural continuity.

## Relationship to Verrell’s Law

CAAI is the applied engineering branch associated with Verrell’s Law.

Verrell’s Law provides the broader theoretical frame that retained information can bias future state selection.

CAAI applies that principle in software through explicit memory weighting, continuity state, Governor logic, and behavioural selection.

This should be read as an engineering instantiation, not as proof that the full theoretical or physical form of Verrell’s Law has been experimentally confirmed.

Public-safe wording:
