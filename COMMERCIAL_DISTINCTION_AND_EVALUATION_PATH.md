# Commercial Distinction and Evaluation Path

**Author:** Marcos Verrell Moss Ross (M.R.)  
**Organisation:** Inappropriate Media Limited / Collapse Aware AI  
**Status:** Public commercial and technical orientation note

---

## 1. Core Distinction

Collapse Aware AI (CAAI) is not positioned as a general claim that memory matters in AI.

That wider idea is now becoming common across AI, agent systems, biology-inspired intelligence, continual learning, and runtime architecture discussions.

CAAI is narrower and more practical:

> CAAI is middleware for governed retained-state behavioural selection.

The important distinction is not merely storing or retrieving memory. The important distinction is controlling how retained state is allowed to influence future behavioural selection under explicit rules.

---

## 2. What CAAI Is Not

CAAI is not:

- a foundation model
- a vector database
- a standard RAG pipeline
- long-context prompting
- ordinary memory storage
- a chatbot skin
- a Unity-only or Unreal-only plugin
- a claim of AGI or machine consciousness
- proof of the full scientific scope of Verrell's Law

CAAI is an engineering layer around runtime behaviour selection.

---

## 3. What CAAI Is

CAAI is designed to sit between a host system and a model, scripted logic layer, agent framework, simulation runtime, or decision engine.

Its public-safe runtime shape is:

```text
Host system / UI / engine
        ↓
Structured input payload
        ↓
Candidate behaviours / possible outputs
        ↓
Retained-state influence
        ↓
Governor constraints
        ↓
Selected behaviour
        ↓
Diagnostic evidence / fallback status
        ↓
Persistent state update
```

The goal is controlled behavioural continuity rather than uncontrolled memory expansion.

---

## 4. Gold Build Core Demo Focus

The Gold Build Core demo should focus on evidence that can be shown without exposing the private implementation:

- structured JSON request / response flow
- engine-agnostic API behaviour
- retained-state influence
- governor-controlled resolution
- persistence and recall evidence
- fallback and validation behaviour
- diagnostic visibility into why an output was selected

The demo should not be presented as a finished AAA NPC brain or a full Phase-2 adaptive agent system.

- game AI / NPC systems teams

## 6. Evaluation Licence Path

The preferred first commercial step is a paid, time-limited Architecture Evaluation Licence under NDA.

The evaluation should let a serious technical party assess:

- local runtime behaviour
- API contract shape
- retained-state influence
- persistence and restart recall
- governor behaviour
- diagnostic visibility
- integration feasibility

The first commercial goal is not to claim universal adoption. The first goal is to secure evidence-backed technical evaluations with the right parties.

## 7. Public Wording To Use

Recommended short wording:

> Collapse Aware AI is engine-agnostic middleware for governed retained-state behavioural selection.

Recommended longer wording:

> Collapse Aware AI sits between candidate generation and final output, allowing retained state, runtime context, and governance rules to influence behavioural selection in an inspectable and measurable way.

Recommended market distinction:

> CAAI is not memory storage. It is a runtime mechanism for governing how retained state affects future behaviour.

A technical reviewer does not need to accept the full research scope of Verrell's Law to evaluate CAAI as middleware.
